    Importação manual (se a SEFAZ bloquear a consulta)

    Abra o link da nota no navegador, salve/copie o código-fonte da página e cole abaixo.

      O link de configuração preenche URL e token em outro aparelho (ex.: celular). Ele contém o token — compartilhe só com quem pode alterar sua planilha.

      Favorito "Enviar para o Gastos"

      Algumas SEFAZ (como a de SP) não deixam o app consultar a nota sozinho. Com este favorito, você abre a nota no navegador e envia a página para o app com um toque.

      Instalar no Chrome do Android (uma vez em cada aparelho):

      1. Toque em Copiar código do favorito.
      2. Nesta página, abra o menu ⋮ e toque na estrela ☆ para criar um favorito.
      3. Toque em Editar. Em Nome, escreva Enviar para o Gastos; em URL, apague o que estiver lá e cole o código. Salve.

      Usar: leia o QR Code na aba Escanear e toque em Abrir a nota. Com a nota aberta, toque na barra de endereço, digite Gastos e toque na sugestão Enviar para o Gastos (com ícone de estrela).

      No computador: arraste este link para a barra de favoritos → Enviar para o Gastos
